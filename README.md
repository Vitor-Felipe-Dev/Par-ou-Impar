# Par ou Ímpar

Script simples em Python que verifica se um número digitado é par ou ímpar.  
O programa continua rodando até que o usuário digite **999** para sair.

## Como executar

1. Certifique-se de ter o Python instalado.
2. Abra o terminal ou prompt de comando.
3. Navegue até a pasta do projeto.
4. Execute o comando:

```bash
python par_ou_impar.py
